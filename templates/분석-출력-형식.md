# AI 답변 템플릿

## 1. 분석 조건
성씨 / 이름(한글·한자) / 출생 정보(제공된 경우만) / 선택한 규칙 / 누락 정보

## 2. 확인된 사실
발음·뜻·한자 음훈·획수·법적 허용 여부. 각 항목에 출처 및 확인 상태.

## 3. 전통 성명학 해석(요청 시)
적용 학파 / 계산식 / 결과 / 다른 학파와의 차이 / 해석의 한계.

## 4. 추천 또는 비교
후보별 의미·발음·실용성·검증 상태. 전통적 길흉을 객관적 점수로 합산하지 않는다.

## 5. 미확인 사항과 다음 확인
필요한 자료, 공식 확인 링크, 판단에 영향을 주는 불확실성.

표현 예시: '이 한자의 인명용 허용 여부는 최신 법원 목록과 대조하지 않아 미확인입니다.'
