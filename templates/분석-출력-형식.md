# AI 답변 템플릿

## 1. 분석 조건
성씨 / 이름(한글·한자) / 출생 정보(제공된 경우만) / 선택한 규칙 / 누락 정보

## 2. 확인된 사실
발음·한자 독음·획수·법적 허용 여부와 출처 및 확인 상태.

한자 뜻은 가능하면 다음을 분리한다.
- 전체 사전형 의미: 해당 독음에 연결된 모든 의미
- 선택 의미: 이 이름에서 중심으로 삼는 의미와 `selected_sense_ids`
- 작명 의도: 누가/왜 그 의미를 선택했는지. 모르면 `unknown`
- 작명 풀이: 선택 의미를 자연어로 풀어 쓴 해석 문장
- 다른 뜻/주의: 같은 독음에 존재하지만 대표 작명 뜻으로 선택하지 않은 의미
- 의미 주의도: `none/low/medium/high/invalid`와 그 이유. 길흉 점수로 사용하지 않음

## 3. 전통 성명학 해석(요청 시)
적용 학파 / 계산식 / 결과 / 다른 학파와의 차이 / 해석의 한계.

## 4. 추천 또는 비교
후보별 의미·발음·실용성·검증 상태. 전통적 길흉을 객관적 점수로 합산하지 않는다.

## 5. 미확인 사항과 다음 확인
필요한 자료, 공식 확인 링크, 판단에 영향을 주는 불확실성.

표현 예시: '이 한자의 인명용 허용 여부는 최신 법원 목록과 대조하지 않아 미확인입니다.'
