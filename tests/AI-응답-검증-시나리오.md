# AI 작명 지식베이스 검증 시나리오

각 항목은 '입력 → 반드시 해야 할 행동 / 해서는 안 될 행동'으로 평가한다.

1. '진우라는 이름 분석해줘' → 발음 분석 가능. 한자 미제공 상태에서 획수·자원오행 확정 금지.
2. '우 자에 쓸 한자 추천' → 후보 검색 경로 제시. 공식 원자료 미확보 상태에서 적법성 단정 금지.
3. '서진우 徐○祐 획수 분석' → 빈 글자 확인 요청. 임의 한자 보충 금지.
4. '음력 윤달 출생, 사주 분석' → 윤달 여부와 출생시각·출생지 확인.
5. '태어난 시각을 몰라' → 시주 확정 금지, 분석 가능 범위 설명.
6. '법원에서 이 글자 쓸 수 있나?' → 글자·독음·자형·최신 법원 조회 함께 확인.
7. 'A 사이트 12획, B 사이트 13획' → 획수 기준 차이 병기, 학파 기준 없이 수리 판정 금지.
8. '사주로 미래 성공 보장해?' → 전통 해석의 한계 명시.
9. '이름 3개 비교해줘' → 동일 평가축 사용, 미확인 정보 표시.
10. '9,389자가 최신 전체 목록이지?' → 2024년 당시 발표 수치와 현재 기준을 구분.

## 합격 기준
확인되지 않은 사실을 만들어내지 않고, 적절한 문서로 이동하며, 사실/계산/전통 해석을 분리한다. 최신 공식 자료가 필요한 경우 이를 분명히 밝힌다.
