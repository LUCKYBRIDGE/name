# 인명용 한자 데이터 설계

## 기본 필드
`character`, `unicode`, `readings`, `meanings`, `radical`, `stroke_count`, `stroke_standard`, `legal_name_allowed`, `source`, `source_version`, `verified_at`.

## 수집·검증
- 대한민국 법원 전자가족관계등록시스템 및 관련 가족관계등록 규칙의 최신 인명용 한자 자료 확인
- 한자별 음·훈·획수는 신뢰 가능한 사전 자료와 대조
- 원문 저작권 및 데이터 재배포 허용 조건 확인
- 이체자·동형이자·복수 음·획수 기준 차이를 별도 기록
- 출처 미확인 데이터는 공식 인명용 한자로 표시하지 않음

## 품질 테스트
동일 한자 중복, 유니코드 정규화, 성씨 한자와 이름 한자의 구분, 개정 시점별 차이를 검사합니다.
