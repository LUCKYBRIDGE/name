# 성명학 규칙 비교

## 조사 대상
- 획수 음양(홀짝)과 배합
- 발음오행: 초성 등을 오행에 대응시키는 규칙
- 자원오행: 한자 자형·부수·뜻에 따른 분류
- 수리성명학: 원격·형격·이격·정격 등 격의 정의와 수리 해석
- 한글 이름과 한자 이름에 서로 다른 규칙 적용 여부

## 설계 원칙
각 규칙은 `rule_id`, `school`, `version`, `formula`, `reference`, `limitations`를 갖습니다. 학파가 다른 계산을 하나의 절대 점수로 합치지 않습니다. 획수 계산에는 기준 사전과 필획/원획 등 채택 기준을 명시합니다.
