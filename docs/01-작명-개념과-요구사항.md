# 작명 웹앱 개념과 요구사항

## 목적
한국식 작명에 필요한 법적·언어적·가족적·전통적 정보를 분리해 사용자가 이름 후보를 만들고 근거를 확인하며 비교할 수 있도록 한다.

## 입력
- 성씨(한글/한자), 본관(선택), 원하는 이름 발음
- 선호·제외 글자와 의미
- 한자별 선택 의미와 작명 의도(선택)
- 출생일시·양력/음력·윤달·출생지/시간대(사주 사용 시)
- 적용할 전통 성명학 method

## 출력
- 후보 이름과 한자별 실제 독음
- 전체 사전형 의미 / 선택 의미 / 다른 뜻·semantic risk / 작명 풀이
- 현행 인명용 한자 검증 상태
- 기술 획수와 method별 성명학 획수 구분
- 발음·실사용성·로마자·유행도
- 요청한 경우 method별 명리·성명학 결과

## 중요 구분
- 공식 법적 사실 ≠ 제3자 후보 미러
- 전체 사전 뜻 ≠ 부모가 선택한 작명 뜻
- Unicode 기술 획수 ≠ 성명학 원획
- 전통 오행·수리 해석 ≠ 과학적 미래예측

## UI 흐름
조건 입력 → 한글 후보 → 한자+독음 후보 → 의미 선택 → 법적/실사용 검증 → 선택한 전통 method 분석 → 후보 비교 → 저장/내보내기.

앱은 `quality-gates.json`에서 미완료로 표시된 데이터 계층을 확정 결과처럼 표시하지 않는다.
