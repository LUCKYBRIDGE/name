# 작명 웹앱 개념과 요구사항

## 목적
한국식 작명에서 참고하는 정보를 통합해 사용자가 이름 후보를 직접 만들고 비교할 수 있도록 한다.

## 입력
- 성씨(한글/한자), 원하는 이름 발음, 선호·제외 글자
- 출생일시(선택), 양력/음력 및 윤달 여부, 출생지/시간대(선택)
- 선택할 성명학 규칙 체계

## 출력
- 후보 이름과 한자별 음·훈·뜻·획수·법적 사용 가능 여부
- 음양·발음오행·수리 결과(적용 규칙 및 근거 명시)
- 사주 관련 결과(계산 검증 후 제공)
- 후보 간 비교 및 로컬 저장

## 중요 구분
- 인명용 한자 등재 여부: 최신 공식 자료로 검증해야 하는 사실
- 한자 획수: 자료·산정 규칙에 따라 차이 가능
- 오행·길흉: 학파별 전통 해석으로, 과학적 예측으로 표시하지 않음

## UI 흐름
조건 입력 → 한글 이름 후보 → 한자 조합 탐색 → 분석 결과 비교 → 즐겨찾기/내보내기.
