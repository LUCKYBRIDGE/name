# 이름용 한자 선택 체크리스트

- [ ] 해당 글자의 정확한 유니코드와 자형 확인
- [ ] 원하는 한글 독음과 사전 독음 일치 확인
- [ ] 기본 뜻과 다른 뜻·부정적 용례 확인
- [ ] 대한민국 인명용 한자 최신 허용 여부 확인
- [ ] 성씨와 결합했을 때 발음·동음이의어·어감 확인
- [ ] 글자 획수와 쓰기 난이도 확인
- [ ] 성명학 요청 시 학파·계산 규칙·획수 기준 명시
- [ ] 출처·확인일·미확인 항목을 답변에 표시

## AI의 결론 표현
'추천 가능'과 '법적으로 이름에 사용 가능'은 다르다. 공식 자료 확인 전에는 '의미상 후보로 검토할 수 있으나 인명용 한자 허용 여부는 미확인'이라고 쓴다.
