# 출생일시 입력 규격

작명·감명에서 사주를 사용하려면 **출생 연월일뿐 아니라 정확한 시각과 출생 장소**를 별도 데이터로 관리한다.

## 필수 입력
| 필드 | 예 | 필요성 |
|---|---|---|
| birth_datetime_local | 2026-12-13 03:42 | 연·월·일·시 계산의 원본 |
| precision | minute / 10min / hour / unknown | 경계 시각의 신뢰도 판단 |
| calendar_input | solar / lunar | 사용자가 제공한 원래 달력 체계 |
| leap_month | true/false/null | 음력 입력이면 필수 |
| birthplace_name | 서울 강서구 | 시간대·경도 검증 |
| timezone_id | Asia/Seoul | 표준시·서머타임 이력 적용 |
| source | hospital_certificate / family_memory / other | 시각의 근거 |
| recorded_time | 03:42 | 기록된 시계 시각 원본 |

## 왜 '분' 단위가 중요한가
의료법 시행규칙의 현행 출생증명서 서식은 출생일시를 **년·월·일·시·분, 24시간제**로 기록하도록 되어 있다. 따라서 가능하면 가족의 기억보다 출생증명서에 기록된 시각을 우선한다.

공식 서식:
https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110202&flSeq=162079341&gubun=

## 추가 계산 필드
- utc_offset_at_birth
- dst_applied
- standardized_datetime
- longitude / latitude
- true_solar_time (사용한 학파가 요구하는 경우만)
- equation_of_time_correction (사용한 학파가 요구하는 경우만)
- nearest_solar_term
- minutes_from_term_boundary
- day_boundary_method
- zi_hour_method

## 시간대 이력
현재 한국은 UTC+9를 사용하지만 과거에는 표준시와 일광절약시간제가 달랐다. 기존 이름 분석까지 지원하려면 생년월일에 맞는 당시 시계 체계를 복원해야 한다.

- 1954-03-21부터 1961-08-10 전까지: UTC+8:30
- 1961-08-10부터: UTC+9
- 역사적으로 여러 해에 일광절약시간제 시행
- 외국 출생자는 해당 국가·지역의 실제 시간대와 DST 이력을 적용

표준시 역사 근거: 국가기록원
https://theme.archives.go.kr/next/koreaOfRecord/summerTime.do

기술적 시간대 이력: IANA tzdb Asia/Seoul
https://data.iana.org/time-zones/tzdb/asia

## 경계 사례
다음은 자동 확정하지 않고 양쪽 결과를 함께 계산한다.
- 입춘·경칩 등 절입 시각 전후 60분 이내
- 자정/자시 경계
- 서머타임 시작·종료 순간
- 시간대 변경일
- 기록 시각의 정밀도가 낮아 경계를 넘을 수 있는 경우

## 출생 전 작명
아직 태어나기 전에는 사주를 확정할 수 없다.
1. 성씨·발음·뜻·한자 적법성 중심의 후보군을 먼저 만든다.
2. 예정일 범위는 참고 시나리오로만 분석한다.
3. 실제 출생 후 출생증명서의 시·분을 입력해 사주 관련 평가를 다시 수행한다.
4. 의료적 출산 시각 결정은 의료진의 판단이 우선이며 작명·명리 분석이 이를 대신하지 않는다.
