# 사주명리 기초체계

## 1. 사주의 구조
전통 명리에서 사주는 출생한 **연·월·일·시**를 각각 간지 두 글자로 나타낸 네 기둥(四柱)이며 총 여덟 글자라 하여 팔자라고도 한다. 천간은 10개, 지지는 12개이며 순차 결합한 60개 조합이 육십갑자다.

### 천간
갑(甲)·을(乙)·병(丙)·정(丁)·무(戊)·기(己)·경(庚)·신(辛)·임(壬)·계(癸)

### 지지
자(子)·축(丑)·인(寅)·묘(卯)·진(辰)·사(巳)·오(午)·미(未)·신(申)·유(酉)·술(戌)·해(亥)

출처: 한국민족문화대백과사전 「사주」, 「역법」

## 2. 천간의 오행 배속
전통적으로 갑·을=목, 병·정=화, 무·기=토, 경·신=금, 임·계=수로 배속한다. 음양은 각 오행의 앞 천간을 양, 뒤 천간을 음으로 보는 통용 체계를 사용한다.

| 천간 | 음양 | 오행 |
|---|---|---|
| 甲 갑 | 양 | 목 |
| 乙 을 | 음 | 목 |
| 丙 병 | 양 | 화 |
| 丁 정 | 음 | 화 |
| 戊 무 | 양 | 토 |
| 己 기 | 음 | 토 |
| 庚 경 | 양 | 금 |
| 辛 신 | 음 | 금 |
| 壬 임 | 양 | 수 |
| 癸 계 | 음 | 수 |

오행 배속 근거: 한국민족문화대백과사전 「윤도」.

## 3. 오행 관계
상생의 전통적 순환은 목→화→토→금→수→목이며, 상극은 목극토·토극수·수극화·화극금·금극목이다.

이 관계는 **전통 이론의 규칙**이지 자연과학적 인과법칙으로 취급하지 않는다.

## 4. 작명에서 사용할 때
사주를 이름 추천에 반영할 경우 다음 세 층을 분리한다.
- 계산층: 달력·절기·간지
- 해석층: 강약·격국·용신 등 선택한 명리 방법론
- 작명층: 발음오행·자원오행·수리 등 선택한 성명학 방법론

AI는 '오행이 하나 없으니 그 오행 글자를 넣으면 된다'처럼 단순 개수만으로 결론내리지 않는다. 용신·격국 등은 학파별 방법론 차이가 크므로 반드시 method_id와 출처를 함께 남긴다.
