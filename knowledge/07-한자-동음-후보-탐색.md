# 한글 독음에서 한자 후보 찾기

## 목적
사용자가 '진우에 쓸 한자', '우 자 중 뜻 좋은 글자'처럼 요청했을 때 필요한 데이터만 검색한다.

## 조회 절차
1. 이름을 음절 단위로 분리한다. 예: 진/우.
2. 각 음절의 **법원 허용 독음**을 기준으로 인명용 한자 후보를 검색한다.
3. 글자별 법적 허용 여부, 정확한 자형·코드포인트, 음훈, 뜻, 획수의 출처를 별도 확인한다.
4. 의미 조합을 제안하고, 성씨와 합친 발음·어감·오해 가능성을 점검한다.
5. 전통 성명학은 사용자가 요청한 학파를 명시한 뒤 별도로 계산한다.
6. 확정·미확정 항목을 구분하여 결과를 제시한다.

## 중요 예외
- 한자 사전의 독음과 출생신고에 허용된 독음은 다를 수 있다.
- 이체자와 유사 글리프는 단순 문자열 일치로 합치지 않는다.
- 다의어는 좋은 뜻 하나만 발췌하지 말고 주요 의미를 함께 제시한다.
- 획수 자료가 없으면 수리성명학 결과를 산출하지 않는다.
- 아직 공식 전체 데이터가 없으므로 **이 문서만으로 특정 한자 조합의 적법성을 판정할 수 없다.**
