# 외부 자료 등록 규칙

모든 출처에 아래 항목을 기록한다.

| 필드 | 의미 |
|---|---|
| source_id | 안정적인 식별자 |
| publisher | 발행기관 |
| title | 문서·데이터명 |
| url | 원문 링크 |
| accessed_at | 실제 확인 날짜 |
| published_or_revised_at | 발행·개정일(알 때만) |
| authority | 공식 법령/공식 서비스/사전/학파 저술/기타 |
| scope | 이 자료가 입증하는 범위 |
| license | 재사용·재배포 조건(미확인 가능) |
| local_copy | 저장소에 사본이 있는지 |
| caveats | 예외·한계 |

### 운영 원칙
- 공식 페이지 링크만 수록했다고 전체 목록을 확보한 것은 아니다.
- 링크가 끊어지거나 개정되면 이전 기준일을 유지하고 최신 확인 상태를 갱신한다.
- 출처 없는 한자 뜻·획수·성명학 분류를 데이터베이스에 넣지 않는다.
- 공식 자료와 사전·전통 해석은 각각 별도 출처를 기록한다.
