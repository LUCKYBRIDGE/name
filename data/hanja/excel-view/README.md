# Excel에서 보기 쉬운 인명용 한자 자료

이 폴더는 GitHub에서 관리하기 쉬우면서 **Microsoft Excel / 한셀 / Google Sheets에서 바로 열어 필터·정렬할 수 있는 CSV 보기본**이다.

## 파일
- `독음별_한자요약.csv`: 독음 1개당 1행. 후보 수와 해당 한자 전체를 한눈에 확인.
- `한자별_마스터.csv`: 한자 1자당 1행. Unicode와 허용 독음 후보를 확인.

두 CSV 모두 UTF-8 BOM을 넣어 Excel에서 한글이 깨질 가능성을 줄였다.

## 추천 사용법
1. Excel에서 파일을 연다.
2. 첫 행에 필터를 적용한다.
3. `독음별_한자요약.csv`에서 '진', '우', '현' 등으로 검색한다.
4. 실제 후보를 정하면 `한자별_마스터.csv`에서 독음과 Unicode를 다시 확인한다.
5. **출생신고 가능 여부는 현행 대법원 인명용 한자 조회에서 최종 검증한다.**

## 왜 XLSX 하나가 아니라 CSV를 기본으로 두나?
GitHub에서는 CSV가 변경 이력을 비교하기 쉽고 AI가 직접 읽기도 쉽다. XLSX는 사람이 보기에는 편하지만 바이너리라 GitHub에서 변경 내용을 비교하기 어렵다. 따라서 **CSV를 원본/기준 데이터로 관리하고, 필요할 때 XLSX 보기본을 생성하는 방식**이 안전하다.
