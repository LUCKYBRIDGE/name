# 인명용 한자 훈음 데이터 — libhangul 결합

## 목적
대법원 인명용 한자 후보의 **허용 독음**과 한국어 **훈음/짧은 뜻**을 AI가 별도 조회할 수 있도록 결합한 보조 데이터다.

## 원천
1. 법적 후보/독음: `rutopio/Korean-Name-Hanja-Charset/data-gov.csv`
   - 2024-07-16 대법원 인명용 한자 조회 기반 제3자 미러
   - 최종 법적 적합성은 현행 대법원 조회로 재확인
2. 훈음: `libhangul/libhangul/data/hanja/hanja.txt`
   - BSD 3-Clause 계열 라이선스
   - 형식: `독음:한자:훈음`

## 결합 통계
- 법원 미러 원행: 10,163
- 독음별 관계로 펼친 행: 11,803
- 훈음 정확 일치: 8,153
- 훈음 미일치: 3,650
- 고유 한자 코드포인트: 9,459
- 한 개 이상의 훈음을 확보한 고유 한자: 7,150

## 파일
- `legal-reading-meaning.csv`: 허용 독음 1건당 1행. AI가 특정 독음의 한자를 고를 때 사용.
- `hanja-meaning-summary.csv`: 한자 1자당 1행. 복수 독음과 독음별 훈음을 한눈에 확인.

## 중요
- `meaning_ko`는 **사전형 훈음**이지 작명상의 길상 의미를 뜻하지 않는다.
- 훈음이 없다고 나쁜 한자가 아니다. 단지 이 출처에서 정확한 (독음,한자) 조합을 찾지 못한 것이다.
- 한 글자에 여러 뜻이 있으면 모두 보존하고 AI가 임의로 하나만 '진짜 뜻'으로 고정하지 않는다.
- 최종 출생신고 가능 여부는 이 파일이 아니라 최신 법원 공식 조회로 판단한다.
