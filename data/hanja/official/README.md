# 현행 공식 인명용 한자 전수 대조 입력

이 폴더는 대법원 현행 인명용 한자표/조회 결과를 정규화한 공식 대조 입력을 두는 자리다.
현재 후보 검색 원본은 2024-07-16 제3자 미러이며, 현행 공식 표와의 전체 차집합 검증은 아직 완료되지 않았다.

## 입력
`official-reading-character.template.csv` 형식을 사용한다.
필수 열은 `reading`, `hanja`, `unicode`다. 가능하면 `legal_category`, `variant_of`, `source_id`, `verified_at`도 채운다.

독음은 한글 한 음절, 한자는 입력한 유니코드 코드포인트와 일치하는 한 글자를 사용한다. 코드포인트는 `4F3D`와 `U+04F3D` 형식을 모두 지원한다. 정규화한 독음과 코드포인트 조합은 한 행씩 기록한다. 빈 양식, 잘못된 코드포인트, 중복 관계 또는 열 개수가 맞지 않는 CSV는 오류로 처리한다.

## 대조
```bash
node scripts/audit/compare-official-hanja.mjs data/hanja/official/official-reading-character.csv official-diff.json
```

비교 기준은 (독음 + Unicode 코드포인트)이다. 대법원이 2024년 발표한 총 9,389자와 저장소의 9,460 코드포인트는 집계 단위가 다를 수 있으므로 숫자만으로 오류를 단정하지 않는다. 보고서는 관계의 차집합과 공통 글자의 독음 차이를 기록한다. 허용자체·동자·속자·약자 범주는 공식 입력의 출처 및 범주 정보와 함께 별도로 검토한다. 대조 결과와 함께 공식 추출 범위도 확인한다.

공식 원본의 재배포 범위를 확인하기 전에는 PDF 원문 복제보다 검증 가능한 정규화 결과와 출처 메타데이터를 우선 저장한다.
