# 인명용 한자 데이터

이 폴더는 AI가 이름 후보를 찾을 때 사용할 **검색용 데이터**와 법적 판단에 필요한 **공식 근거**를 분리한다.

## 현재 확보 상태
- 공식 법적 근거: 확보 (sources/ 및 knowledge/05-인명용한자-법적판정.md)
- 대법원 인명용 한자표 PDF URL: 확보
- 대법원 조회 결과 기반 제3자 데이터 미러: 확보
- 2026-11-14 현재 공식 사이트와의 전체 행 단위 재검증: **미완료**
- 한자별 훈(뜻)·부수·표준 총획수: 별도 사전 데이터 보강 필요

## 바로 사용할 파일
- normalized/by-reading.csv - '진', '우', '서'처럼 읽는 소리로 후보를 검색
- normalized/characters.csv - 한 글자의 허용 독음 후보를 확인
- normalized/reading-index.json - AI/코드에서 빠르게 조회
- raw/rutopio-data-gov-2024-07-16.csv - 변환 전 보존본
- SECONDARY_MIRROR.md - 데이터 출처와 주의사항
- SOURCE_STATUS.md - 공식 원본 상태

## AI 사용 규칙
1. 후보 탐색은 normalized/reading-index.json 또는 by-reading.csv를 사용한다.
2. 후보를 찾았다고 해서 곧바로 '현재 법적으로 사용 가능'이라고 단정하지 않는다.
3. 최종 적법성은 대법원 조회 + 현행 규칙 제37조·별표 1·별표 2로 확인한다.
4. 뜻·훈·획수는 이 데이터에 없으므로 다른 검증된 사전 출처와 결합한다.
5. 복수 독음, 두음법칙, 허용자체는 별도 예외 규칙을 적용한다.
