# 이름 유행·실사용 통계

이 폴더는 이름의 **인기·희소성·추세**를 전통 성명학과 분리해 관리한다.

현재 공식 1차 출처로 대한민국 법원 전자가족관계등록시스템의 다음 통계를 등록했다.

- 상위 출생신고 이름 현황
- 상위 개명신고 이름 현황

대법원은 가족관계등록 통계를 정기적으로 공개한다고 안내하고 있다. 다만 웹 통계의 자동수집·대량 재배포 조건은 별도 확인이 필요하므로 현재는 source registry 단계다.

## 향후 저장 단위

- 기준 기간
- 성별
- 이름(한글)
- 순위
- 신고 건수 또는 공식 제공 수치
- 출생/개명 구분
- source_id
- 조회일
- 원자료인지 파생 추세인지

## 사용 원칙

- 인기 이름 = 좋은 이름으로 해석하지 않는다.
- 희귀 이름 = 나쁜 이름으로 해석하지 않는다.
- 출생신고와 개명신고 순위를 섞지 않는다.
- 연도·기간이 다른 순위를 직접 비교할 때는 모집단과 집계기간을 함께 표시한다.
