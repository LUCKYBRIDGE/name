# 이름 유행·실사용 통계

이 폴더는 이름의 **인기·희소성·추세**를 전통 성명학과 분리해 관리한다.

현재 공식 1차 출처는 대한민국 법원 전자가족관계등록 통계서비스다.

- 상위 출생신고 이름 현황
- 상위 개명신고 이름 현황

법원 통계의 재이용 정책은 출처 표시 조건으로 확인했으며, 현재 단계는 **정규화 스냅샷 스키마 준비 완료 / 직접 공식 조회값 적재 대기**다. 통계는 등록일 기준 잠정치이므로 스냅샷마다 조회조건과 조회일을 보존한다.

## 파일

- `name-trend-source-registry.csv`: 공식 통계 종류와 상태
- `name-trend-snapshot.schema.json`: 공식 TOP20 스냅샷 저장 형식
- `name-trend-ingestion-policy.json`: 수집·보존·파생지표 정책

## 스냅샷 필수 정보

- 출생/개명 구분
- 기준 기간 시작·종료
- 지역
- 성별
- 이름(한글)
- 공식 순위(1~20)
- 공식 신고 건수
- source_id
- 조회일시
- 등록일 기준 잠정치 여부
- 출처 표시문

## 사용 원칙

- 공식 화면에 없는 TOP20 밖 순위·건수는 추정하지 않는다.
- 인기 이름 = 좋은 이름으로 해석하지 않는다.
- 희귀 이름 = 나쁜 이름으로 해석하지 않는다.
- 출생신고와 개명신고 순위를 섞지 않는다.
- 연도·기간이 다른 순위를 비교할 때 모집단과 집계기간을 함께 표시한다.
- 최근 1년/5년/10년 추세 같은 파생값은 원 스냅샷 ID를 추적할 수 있어야 한다.
