# 이름 등록·인명용 한자 법적 규칙

작명 앱에서 **법적 사용 가능 여부**를 전통 성명학이나 한자 의미와 분리하기 위한 규칙 DB다.

- 근거 법령: `KR_LAW_NAME_RULE`
- 현행 조회: `KR_COURT_HANJA`
- 정적 한자 미러는 후보 탐색용이며 현재 법적 전체목록의 확정판으로 표현하지 않는다.
- 법령·예규·공식 조회가 변경되면 `verified_on`과 규칙 상태를 다시 확인한다.

현재 공식 규칙상 인명용 한자의 범위는 「가족관계의 등록 등에 관한 규칙」 제37조를 기준으로 하며, 실제 한자·독음 사용 가능 여부는 전자가족관계등록시스템의 인명용 한자 조회를 최종 확인 수단으로 둔다.
