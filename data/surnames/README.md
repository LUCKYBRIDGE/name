# 성씨 데이터

작명 앱에서 **성씨를 이름자와 분리**하여 처리하기 위한 구조화 데이터다.

현재 코어 범위는 2015 인구주택총조사 **성씨 순위 1~31위**다. 기존에 구축한 徐(13위)를 포함해 총 31개 레코드이며, 이번 확장 대상 30개는 `top30-excluding-xu-2015.csv`에 별도 기록했다. 공식 총조사에서 상위 10대 성씨 순위는 金·李·朴·崔·鄭·姜·趙·尹·張·林 순이다.

## 파일
- `surnames.csv`: 31개 성씨 기본 마스터
- `top30-excluding-xu-2015.csv`: 徐를 제외하고 새로 구축한 30개 성씨와 원 순위
- `entries/<한자>.json`: 성씨별 상세 레코드
- `entries/README.md`: 상세 JSON 스키마
- `pronunciation-profiles.csv`: 31개 성씨 음절 구조
- `stroke-policies.csv`: 기술 총획과 성명학 획수 사용 정책
- `hangul-hanja-disambiguation.csv`: 조(趙/曺), 유(柳/劉), 두음법칙 등 구분
- `representative-clans-2015.csv`: 공식 보도자료의 대표 본관 20개 행
- `clans-2015.csv`: 徐의 본관별 완결형 통계
- `clan-history.csv`: 徐 본관 역사 참고와 근거 수준
- `pronunciation-heuristics.csv`: 성씨-이름 발음·의미 평가 안전 규칙

## 현재 코어 성씨
金 김, 李 이, 朴 박, 崔 최, 鄭 정, 姜 강, 趙 조, 尹 윤, 張 장, 林 임, 韓 한, 吳 오, 徐 서, 申 신, 權 권, 黃 황, 安 안, 宋 송, 全 전, 洪 홍, 柳 유, 高 고, 文 문, 梁 양, 孫 손, 裵 배, 曺 조, 白 백, 許 허, 劉 유, 南 남.

## 핵심 원칙
1. **같은 한글 성씨라도 한자가 다르면 별도 레코드다.**
   - 조(趙) ≠ 조(曺)
   - 유(柳) ≠ 유(劉)
2. **두음법칙·성씨 표기를 보존한다.**
   - 李: 리/이, 林: 림/임, 柳·劉: 류/유, 梁: 량/양
3. **성씨 뜻은 이름자 의미 점수로 자동 환산하지 않는다.**
4. **기술 총획과 수리성명학 획수를 분리한다.**
   - 모든 코어 성씨의 `numerology_default_count`는 현재 비어 있다.
   - method_id별 근거가 생기기 전에는 자동 수리 계산에 투입하지 않는다.
5. **본관은 가족 맥락이다.**
   - `representative-clans-2015.csv`는 대표 본관 참고일 뿐 전체 목록이 아니다.
6. **통계에는 기준시점을 붙인다.**
   - 2015-11-01 인구주택총조사 기준.
7. **로마자 규칙형과 실제 여권 표기를 구분한다.**

## 구축 범위의 한계
- 31개 성씨 모두 한자·훈·Unicode·기술 총획·2015 인구·순위·발음 프로필·로마자 규칙형을 갖는다.
- 徐는 본관 전체 합계와 역사 근거까지 더 깊게 구축되어 있다.
- 다른 성씨의 전체 본관 목록·시조·분파·항렬은 검증 가능한 자료를 추가 확보하면서 단계적으로 확장한다.
