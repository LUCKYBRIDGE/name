# 성씨 데이터

이 폴더는 작명 앱에서 **성씨를 이름자와 분리하여 처리**하기 위한 구조화 데이터다.

현재는 첫 기준 레코드로 `徐(서)`를 구축했다. 성씨 전체를 한꺼번에 채우기보다 출처·필드·검증 방식을 먼저 고정한 뒤 확장한다.

## 파일
- `surnames.csv`: 성씨 한자별 기본 마스터
- `clans-2015.csv`: 2015 인구주택총조사 기준 본관별 통계
- `entries/徐.json`: 徐 성씨 상세 레코드
- `entries/徐-strokes.json`: 徐 획수 기준과 수리 계산 사용 정책
- `pronunciation-profiles.csv`: 성씨 음절 구조와 경계 발음 프로필
- `pronunciation-heuristics.csv`: 작명 앱 발음·의미·획수 안전 규칙
- `clan-history.csv`: 출처 수준을 구분한 본관 역사 참고

## 핵심 원칙
1. **성씨와 이름자는 역할을 분리한다.**
   - 徐의 사전적 훈은 저장하되 이름자의 의미 점수처럼 평가하지 않는다.
2. **성씨 한자를 정확히 받는다.**
   - 한글 '서'만으로 徐·俆·西·書·緖 등을 자동 동일시하지 않는다.
3. **획수는 기준을 분리한다.**
   - 기술 총획과 성명학 method별 적용 획수를 동일시하지 않는다.
4. **본관은 가족 맥락 데이터다.**
   - 본관이 다르다는 사실을 이름의 길흉 점수로 자동 환산하지 않는다.
5. **통계는 기준시점을 유지한다.**
   - 현재 수록 인구는 2015-11-01 인구주택총조사 기준이다.
6. **로마자 표기는 참고값과 실제 법적 표기를 구분한다.**
   - 규칙상 '서'의 기본 로마자형은 Seo지만 기존 여권·가족 표기와 다를 수 있다.

## 徐 요약
- 한글: 서
- 한자: 徐
- Unicode: U+5F90
- 훈: 천천할 서
- 부수: 彳
- 기술 총획 참고: 10
- 2015 인구: 751,704명
- 2015 본관 통계 주요 항목: 달성·이천·대구·부여·장성·연산·남양
- 로마자 규칙형: Seo

정확한 상세값과 출처는 `entries/徐.json`을 참조한다.

## 徐 작명 앱 처리 요약
- 음절 구조: ㅅ+ㅓ, 종성 없음(CV)
- 성-이름 경계: 성씨 종성으로 인한 연음·비음화·유음화·받침 유발 경음화 대상이 아님
- '서+서…' 반복: 실사용성 확인용 notice만 표시
- 기술 총획 10: 사전/기술 참고값이며 수리성명학 기본값으로 사용하지 않음
- 이천 본관: 서신일 시조 서술을 학술 참고자료로 연결
- 달성 본관: 서진 시조 전승을 공공 문화·지역사 자료로 교차 표시
- 대구 분파 관계: 공공 문화자료의 계통 전승으로만 저장하고 확정 사실처럼 확대하지 않음
