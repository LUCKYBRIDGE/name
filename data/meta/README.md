# 데이터 메타데이터

이 폴더는 `data/` 전체의 **공통 출처·스키마 버전·통계 기준**을 관리한다.

## 파일
- `sources.csv`: 외부 원천의 안정적인 `source_id` 등록부
- `dataset-stats.json`: 데이터셋 행 수·커버리지·정규화 상태의 단일 기준
- `schema-version.json`: 구조화 데이터 스키마 버전과 공통 규칙

## 운영 원칙
1. README에 데이터 개수를 직접 복제하기보다 `dataset-stats.json`을 기준으로 설명한다.
2. 새 CSV/JSON에는 가능하면 원문 URL을 반복하지 않고 `source_id`를 사용한다.
3. 학파·저자·계산법에 따라 달라지는 값은 `method_id`를 반드시 유지한다.
4. 공식·기술·학술·제3자 미러의 권위 수준을 구분한다.
5. 후보 검색용 한자 데이터와 현행 법적 판정을 동일시하지 않는다.
