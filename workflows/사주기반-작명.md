# 요청 유형: 사주를 반영한 이름 추천

## 입력
- 성씨 한글/한자
- 출생 연월일시
- 양력/음력, 음력일 경우 윤달 여부
- 출생지/시간대
- 성별은 사용자가 특정 전통 규칙에서 필요하다고 요청할 때만 사용
- 선호 발음·뜻·피하고 싶은 글자·항렬자
- 적용할 성명학 방법론(없으면 복수 방법론을 분리 제시)

## 처리
1. **달력 검증**: KASI 자료로 절기·날짜 경계를 확인한다.
2. **사주 원국 계산**: 선택한 명리 계산 규칙을 기록한다.
3. **해석 방법 선택**: 강약·격국·용신 등 사용할 방법론과 출처를 고정한다.
4. **한글 후보 생성**: 발음 자연스러움·성씨와의 연결·동음이의·부정적 연상을 먼저 점검한다.
5. **한자 후보 탐색**: 법원 인명용 한자 데이터에서 독음별 후보를 찾는다.
6. **한자 검증**: 법적 허용 독음·자형을 공식 조회에서 재확인한다.
7. **의미 평가**: 사전적 뜻과 작명 해석을 분리한다.
8. **성명학 평가**: 발음오행·자원오행·81수리를 선택한 학파별로 각각 계산한다.
9. **후보 비교**: 실사용성 / 의미 / 법적 검증 / 전통 해석을 별도 열로 제시한다.

## 금지
- 부족한 오행 하나만 보고 특정 한자를 자동 추천
- 최신 법원 확인 없이 '출생신고 가능' 확정
- 서로 다른 획수 기준과 길흉표를 혼합
- 사주·성명학 결과를 과학적으로 입증된 미래 예측처럼 표현

## 최종 결과 권장 순서
1. 추천 이름 5~10개
2. 한글 이름의 발음·어감
3. 가능한 한자 조합
4. 법적 인명용 검증 상태
5. 한자 의미
6. 적용한 명리/성명학 방법별 결과
7. 학파에 따라 달라지는 부분
8. 최종 선택 시 실생활 체크사항
