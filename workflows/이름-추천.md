# 요청 유형: 이름 추천

## 필요한 정보
성씨(가능하면 한자), 원하는 이름의 글자 수, 선호 발음·의미, 제외 글자. 사주를 원할 때만 출생정보를 추가로 요청한다.

## 순서
1. 사용자의 우선순위(발음/뜻/한자/전통 성명학)를 파악한다.
2. 발음과 의미가 서로 다른 한글 이름 후보를 제안한다.
3. 한자를 붙일 때에는 각 한자의 독음·인명용 허용 여부를 별도 검증한다.
4. 각 한자는 `meaning-senses.csv`에서 해당 독음의 **모든 의미**를 확인한다.
5. 이름에 중심으로 사용할 의미를 문서화된 의미 중에서 선택하고 `selected_sense_ids`, `selection_origin`, `naming_intent`를 기록한다.
6. `semantic-risk-rules.csv`에 따라 선택 근거와 다른 뜻의 주의 수준을 평가한다. 다른 뜻이 불편하다는 이유만으로 자동 탈락시키지 않는다.
7. 작명 풀이 문장은 선택 의미를 자연스럽게 풀어 쓰되 사전 정의처럼 표시하지 않는다.
8. 선택하지 않은 다른 사전형 뜻이 있으면 숨기지 않고 필요 시 함께 제시한다.
9. 요청 시에만 학파를 밝히고 수리·오행·사주 해석을 덧붙인다.
10. 추천 이유와 미확인 사항을 함께 제시한다.

## 금지
확인하지 않은 한자를 공식 인명용 한자라고 단정하지 않는다. 사전에 없는 좋은 뜻을 만들어 붙이지 않는다. 다른 독음의 뜻을 현재 이름 독음에 섞지 않는다. 전통적 길흉을 과학적 사실처럼 점수화하지 않는다.
