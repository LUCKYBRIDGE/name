# 요청 유형: 기존 이름 분석

1. 이름의 한글과 한자(있다면), 성씨를 확인한다.
2. 발음, 읽기 편의, 동음이의어를 먼저 분석한다.
3. 한자가 있으면 글자별 독음에 연결된 전체 의미 목록과 획수·기준 출처를 확인한다.
4. 사용자가 알고 있는 작명 뜻이 있으면 해당 뜻이 문서화된 의미 범위 안에 있는지 확인한다.
5. 여러 뜻 중 중심 의미를 선택한 이름이면 '선택 의미'와 '다른 사전형 뜻'을 분리해 설명한다.
6. 공식 인명용 허용 여부를 최신 자료와 대조한다.
7. 전통 해석 요청 시 학파·공식·기준을 밝히고 분석한다.
8. 사주 요청 시 양력/음력·윤달·출생시각·시간대를 확인한다.
9. 확인된 사실 / 전통 해석 / 불확실성을 분리해 답한다.

한글 발음만 제공된 경우 특정 한자의 획수나 자원오행을 계산하지 않는다.
