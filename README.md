## 핵심 원칙
- **법적 사실**(인명용 한자 허용 여부), **재현 가능한 계산**(획수·달력·간지), **전통적 해석**(사주·성명학)을 혼동하지 않습니다.
- 사주·성명학의 길흉은 과학적으로 검증된 미래 예측이 아닙니다.
- 학파별 규칙 차이를 공개하고, 적용 규칙·출처·기준일을 함께 기록합니다.
- 공식 한자 목록·사전 데이터가 아직 구축되지 않았으므로 실제 이름 분석 시 최신 자료 확인이 필요합니다.
- 개인의 출생 정보는 불필요하게 저장하거나 외부에 전송하지 않습니다.

## 자료 확장 방향
공식 인명용 한자 목록, 한자 음훈·획수의 검증된 데이터, 학파별 계산 규칙과 사례, 경계일 사주 계산 테스트를 단계적으로 축적합니다. 검증되지 않은 내용을 지식으로 확정해 저장하지 않습니다.

> 이 저장소는 현재 AI 사용 지침과 조사 골격을 갖춘 초기 버전이며, 완성된 인명용 한자 사전이나 사주 계산 데이터베이스는 아닙니다.
