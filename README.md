# NAME — 한국식 작명 연구 및 개인용 웹앱

한국의 작명 관행을 조사하고, 이름 후보의 한글 발음·인명용 한자·획수·음양오행·사주 관련 해석을 한곳에서 비교하는 개인용 프로젝트입니다.

## 원칙
- **법적 사실**(인명용 한자 등), **재현 가능한 계산**(획수·날짜 변환), **전통적 해석**(성명학·사주)을 분리합니다.
- 성명학과 사주는 이름의 운명을 과학적으로 예측하는 검증된 방법이 아닙니다. 특정 점수를 객관적인 좋고 나쁨으로 표시하지 않습니다.
- 학파마다 획수 산정·오행 대응·수리 해석이 다를 수 있으므로 규칙별 출처와 버전을 저장합니다.
- 출생일시와 이름 후보는 민감한 개인정보가 될 수 있으므로 기본적으로 브라우저 로컬에서 처리하고 외부 전송을 피합니다.
- 한자 데이터는 공식 출처의 최신 인명용 한자 여부를 확인한 후 사용합니다.

## 연구 주제
1. 인명용 한자: 음·훈·획수·부수·유니코드·허용 여부
2. 사주: 양력/음력·윤달·절기·시각·시간대와 사주팔자 계산
3. 성명학: 발음오행·자원오행·음양·수리·원형이정
4. 추천: 발음 자연스러움, 의미, 선호 조건, 한자 조합, 해석별 비교
5. 검증: 데이터 출처, 계산 테스트, 학파 간 차이

## 폴더
- `docs/`: 이론 및 요구사항
- `research/`: 검증 계획과 참고자료
- `data/`: 추후 검증된 한자·성씨 데이터
- `web/`: 추후 웹앱 구현

## 개발 순서
1. 법적 인명용 한자 데이터의 공식 출처·갱신 방식 확인
2. 한자 검색 및 이름 후보 저장 MVP
3. 획수·음양·발음오행을 학파별 선택형 규칙으로 구현
4. 절기와 시간대가 반영된 사주 계산 엔진 검증
5. 추천 및 비교 화면 개발

> 현재 문서는 설계 초안이며 실제 한자 데이터와 작명 판정 엔진은 아직 구현되지 않았습니다.
