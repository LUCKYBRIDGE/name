# 출생 전 후보 → 출생 후 최종 확정 워크플로

## 1단계: 출생 전
아직 출생일시가 확정되지 않았다면 사주를 확정하지 않는다.

미리 할 수 있는 것:
- 성씨와 어울리는 한글 이름 후보
- 이름의 뜻·어감
- 인명용 한자 후보
- 법적 사용 가능성
- 획수 기준별 후보 자료
- 항렬자·가족 선호
- 로마자 표기·실사용성
- 이름 유행도

결과: **후보 풀 10~30개**를 만든다.

## 2단계: 출생 직후
가능하면 병원 출생증명서에 기록된 '년·월·일·시·분'을 사용한다.
- 출생지
- 당시 시간대
- 절입 경계
- 시주 경계
를 다시 계산한다.

## 3단계: 사주 반영 재필터링
사주를 적용하는 사용자의 선택한 방법론에 따라 후보를 좁힌다.
- 명리 해석 method A
- 명리 해석 method B
- 발음오행
- 자원오행
- 81수리

각 결과는 합산하지 않고 별도 열로 둔다.

## 4단계: 최종 인간 판단
법적 적합성, 부모 선호, 의미, 발음, 실제 사용 편의, 국제 사용을 함께 보아 최종 결정한다.

## 의료 안전
예정된 출산의 날짜·시각을 이름이나 사주 때문에 변경하도록 권하지 않는다. 의료적 안전과 산모·아기의 상태를 우선한다.
