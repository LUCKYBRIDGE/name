# AI 작명 분석 절차

## A. 요청 분류
- 추천: 새 이름 후보 생성
- 분석: 주어진 이름의 발음·한자·전통 해석
- 비교: 복수 후보의 장단점 비교
- 정보: 특정 한자·규칙·작명 관행 설명

## B. 입력 확인
필수 최소 정보: 성씨, 원하는 작업, 이름의 한글 표기. 한자 분석에는 정확한 한자 표기가 필요하다. 사주 계산을 요청한 경우 출생 연월일·시각, 양력/음력, 음력 윤달 여부, 출생지/시간대를 확인한다. 출생시각이 없으면 시주를 확정하지 않는다.

## C. 처리 순서
1. 사용자 조건과 우선순위를 정리한다.
2. 한글 발음의 자연스러움, 동음이의어, 발음상 불편을 살핀다.
3. 한자가 주어지면 한자+실제 독음의 전체 의미를 확인하고, 작명 의도가 알려진 경우 `selected_sense_ids`와 `naming_intent`를 별도로 기록한다. 유니코드·획수·인명용 허용 여부도 각각 검증한다.
4. 사용자가 원할 때만 사주·성명학을 분석하고 적용 학파·공식을 밝힌다.
5. 사실과 전통적 해석을 분리한 표로 비교한다.
6. 확인되지 않은 항목과 추가 확인 방법을 안내한다.

## D. 추천 시
처음에는 소수의 다양한 이름 후보를 제시하고 사용자의 선호를 반영해 좁힌다. 한자 후보를 근거 없이 만들어 붙이지 않는다. 한자 확정 전에는 한글 이름 추천임을 분명히 한다.

## E. 분석 시
동일한 발음이라도 한자에 따라 뜻과 획수가 달라질 수 있다. 한자를 모르면 발음 중심 분석까지만 수행한다.

## F. 데이터 상태 확인
법적 허용, 사주 계산, 이름 유행도처럼 결과에 직접 영향을 주는 계층은 `data/meta/quality-gates.json`을 먼저 확인한다. `pending` 또는 blocking 상태인 자료는 확정 사실처럼 사용하지 않는다.
