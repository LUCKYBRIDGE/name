# 한자 분석 표준 절차

## 1. 입력 확인
한글 이름과 정확한 한자 표기를 받는다. 한글 발음만으로 특정 한자를 확정하지 않는다. 성씨 한자와 이름 한자를 분리한다.

## 2. 각 한자에 대해 독립적으로 확인
1. 글자 원형과 유니코드 코드포인트
2. 한자 음과 훈(복수 음·훈 포함)
3. 사전적 의미와 이름에 적용할 때의 해석(구분)
4. 부수와 총획수, 획수 산정 출처
5. 이체자/동형이자/간체자 혼동 여부
6. 최신 대한민국 인명용 한자 허용 여부(법원 공식 자료)
7. 자원오행·수리 계산은 **선택한 학파 규칙**을 확인한 경우에만

## 3. 검증 상태
- verified: 원자료와 날짜를 확인함
- provisional: 신뢰 가능한 2차 자료만 확인함
- unverified: 출처 미확인
- conflicting: 출처 사이 불일치

인명용 한자 적법성은 verified가 아니면 '사용 가능'이라고 단정하지 않는다.

## 4. 주의
동일 발음의 한자마다 뜻·획수·법적 허용 여부가 달라질 수 있다. 한자 뜻의 아름다움과 길흉 점수는 별개의 판단이다. '인명용 한자'라는 표현은 대한민국의 가족관계등록 관련 규정에서 허용하는 한자를 뜻하며, 일반 한자사전 수록 여부와 동일하지 않다.
