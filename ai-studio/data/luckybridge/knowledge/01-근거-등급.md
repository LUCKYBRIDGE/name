# 근거 등급과 충돌 처리

| 등급 | 유형 | 응답 규칙 |
|---|---|---|
| A | 최신 공식 법령·법원 인명용 한자 자료 | 자료명·시점·링크 표시 |
| B | 검증된 사전·표준 계산 데이터 | 기준·버전·계산 절차 표시 |
| C | 명시된 성명학 학파의 전통 규칙 | 학파·출처·견해 차이 표시 |
| D | 출처 불명 인터넷 주장 | 확정적 판정에 사용 금지 |

서로 다른 자료가 충돌하면 출처·기준 시점·적용 범위를 비교한다. 검증 불가능한 항목은 미확인으로 표시한다.

**중요:** 공식 자료 링크가 있다는 사실만으로 해당 한자가 현재 허용된다고 판정할 수 없다. 실제 목록을 확인해야 한다.
